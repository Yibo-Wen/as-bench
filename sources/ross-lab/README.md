# Ross group (NIST), with Simon d'Oelsnitz (Harvard)

Quantitative deep mutational scanning of allosteric transcription-factor biosensors. The
deposited RamR scan infers a full dose-response function for each of ~309,000 library
members from a growth-based massively parallel reporter assay, so every variant carries a
ligand-free background, a dynamic range, an EC50, a Hill coefficient, and a specificity
score, each with an uncertainty.
